## 1.0.0

The first release, and the state this changelog starts from. Everything before
it is in `docs/CONTEXT.md`, which is an execution log rather than a release
history.

### Features

- A constraint-driven weekly timetable planner for a single Windows machine:
  Electron shell, React renderer, bespoke constraint engine in a Web Worker.
- 500 named constraints as data — 410 hard, 90 soft; 301 enforced by the
  engine, 199 tracked as advisory and labelled as such everywhere.
- Every rejection is explained by constraint number.
- Institution setup separated from term setup, so a timetable manager never
  touches the figures that do not change.
- CSV import for staff, rooms and courses, with every refused row reported by
  line and reason.
- Academic calendar: term dates, holidays, observances and institution events,
  all of which reach the timetable.
- Local assistant over Ollama, with a deterministic explainer as the fallback
  when no model is installed.

### Notes

Nothing is transmitted. There is no server, no database and no account.
